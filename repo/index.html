ENVY BLACK VEIL packages

The packages that turn AlmaLinux 10 + KDE Plasma 6 into ENVY BLACK VEIL: its theme, its release files and tools, and its live-media support. Each one is signed with the project's key. BLACK VEIL's dnf gets its updates from here, along with AlmaLinux's own.

Add it

BLACK VEIL 0.2 and later have it already. On 0.1.0, which came out before this repository:

sudo dnf config-manager --add-repo https://xzchick.github.io/envy-black-veil/envy-black-veil.repo
sudo dnf upgrade

dnf shows the key's fingerprint before it imports it. Go on only if it matches the one below.

The signing key

@FINGERPRINT@

RSA 4096: RPM-GPG-KEY-envy-black-veil. The repository's metadata is signed too (repomd.xml.asc). For dnf to check it, add repo_gpgcheck=1 to the repository file.
